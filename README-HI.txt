RK ONLINE BAZAR — वेबसाइट ZIP

शुरू कैसे करें:
1. ZIP फाइल Extract करें।
2. index.html को Chrome या किसी ब्राउज़र में खोलें।
3. इंटरनेट चालू रखने पर Google Fonts लोड होंगे; बाकी वेबसाइट लोकल फाइलों से चलती है।

फाइलें:
- index.html : वेबसाइट का पेज
- style.css  : डिजाइन और 3D इफेक्ट
- app.js     : प्रोडक्ट, कार्ट, दुकानदार फॉर्म और डेमो ऑर्डर
- README-HI.txt : यह निर्देश

महत्वपूर्ण सीमाएँ:
यह शुरुआती FRONT-END DEMO है, लाइव ई-कॉमर्स सिस्टम नहीं।
- उत्पाद, कार्ट और डेमो ऑर्डर उसी ब्राउज़र/device के localStorage में सेव होते हैं।
- दूसरे मोबाइल/कंप्यूटर पर अपने-आप सिंक नहीं होंगे।
- असली ग्राहक/दुकानदार अकाउंट, सुरक्षित Admin Panel, सर्वर पर फोटो अपलोड,
  सभी डिवाइस पर ऑर्डर दिखना, नोटिफिकेशन, डिलीवरी और ऑनलाइन भुगतान शामिल नहीं हैं।
- असली इस्तेमाल से पहले Firebase/Supabase जैसे backend, authentication,
  database, storage, security rules और payment provider का सुरक्षित integration चाहिए।
- इस डेमो में कोई वास्तविक भुगतान न लें और असली ग्राहक की निजी जानकारी जमा न करें।

फ्री में ऑनलाइन प्रकाशित करने के लिए:
GitHub Pages या Cloudflare Pages जैसे static hosting विकल्प इस्तेमाल किए जा सकते हैं।
पहले ZIP को extract करके उसकी फाइलें hosting project में upload करें।
