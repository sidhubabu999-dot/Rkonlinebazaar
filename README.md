# RK Online Bazaar

बिहार के स्थानीय दुकानदारों और ग्राहकों के लिए शुरुआती responsive marketplace demo.

## GitHub में इस्तेमाल
इन चारों फाइलों को repository के मुख्य स्थान (root) में upload करें:
- `index.html`
- `style.css`
- `script.js`
- `README.md`

## अभी क्या काम करता है
- मोबाइल-फ्रेंडली होमपेज
- कैटेगरी के अनुसार demo products
- सामान खोजने का बॉक्स
- ब्राउज़र में सेव रहने वाला demo cart
- seller interest demo form
- बिहार के जिलों का चयन

## जरूरी सीमा
यह केवल frontend demo है। अभी वास्तविक customer/seller accounts, server/database, admin approval, product uploads, live inventory, real orders, delivery tracking, OTP, wallets, payments और AI features जुड़े नहीं हैं। इन्हें चालू करने के लिए सुरक्षित backend, database और अधिकृत payment/verification providers की जरूरत होगी। कोई असली ग्राहक डेटा या भुगतान इस demo में न लें।
